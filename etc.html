기타 사항 안내

1. 제작 (Crafting)

  • 조합법 안내 : 아이템의 조합법은 패치노트를 통해 올라갈 예정입니다.

2. 맵 제작 및 시스템 정보

  • 배경 : 바탕 맵은 해외 맵을 기반으로 제작되었습니다.
  • 건축물 : 스케메틱 파일, 직접 건축, 그리고 모드 건축 방식을 모두 활용하였습니다.
  • 제작 방식 : 몬스터와 무기/갑옷의 디자인을 제외한 서버의 모든 기능은 자체 제작한 스크립트를 기반으로 작동합니다.
  • 디자인 활용 : 몬스터와 무기/장비 디자인은 자체 제작, 모드, 아머러즈 파일을 활용하였습니다.

3. 퀘스트 (Quest)

  • 퀘스트 내용은 채팅을 통해 안내되므로, 게임 진행 시 유의해서 잘 읽어주시길 바랍니다.
  • 퀘스트 목록을 통해 간략한 내용을 확인하실 수 있습니다.

4. 쿠폰 (Coupon)

  • 입력 방법 : 채팅창에 /쿠폰입력 [쿠폰번호]를 입력하여 사용합니다.
  • 번호 유형 : 공개된 쿠폰번호와 소수에게만 제공되는 비공개 쿠폰번호가 존재할 수 있습니다.
  • 사용 제한 : 쿠폰은 계정당 1회만 사용 가능합니다.

5. 레벨 (Level)

  • >최대 레벨은 현재 500레벨로 차후에 더 올라갈 수도 있습니다
  • 레벨당 스텟
  • - 0~99레벨 : 4sp
  • - 100~199레벨 : 8sp
  • - 200~299레벨 : 12sp
  • - 300~399레벨 : 16sp
  • - 400~499레벨 : 20sp

6. 유적 (Ruins)

  • 맵 곳곳에는 네더라이트 블럭이 있습니다
  • 우클릭 시 유적 내부로 이동하게 되며 점프맵 또는 드로퍼를 클리어 하면 보상을 얻습니다
  • 점프맵의 난이도는 매우 어려움~매우 쉬움 등 다양합니다
  • 중간에 포기를 원할 시 월드이동 탭에서 이동하면 됩니다
  • 보상은 추가 스텟, 경험치, 포션, 히든 스킬 등 다양합니다

7. 은행 (Bank)

  • 마을 마다 은행원이 있습니다
  • 은행원에게서 돈을 인출 가능합니다
  • /수표 금액 개수 명령어를 통해 수표를 인출 가능합니다
  • 명령어를 통해 인출 시 은행원으로 인출하는 것 대비 3%의 수수료가 붙습니다

8. 친구 소환 (Teleport)

  • 친구를 소환할 수 있습니다
  • /소환 닉네임 으로 소환 가능합니다
  • 5초간 요청이 유지되며 수락시 이동됩니다
